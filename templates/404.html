How to Use This App

Top Species

Find the most observed species near a location in Minnesota.

/top_species/<location>/<radius>/<top_n>
  • location: City name, e.g. Northfield
  • radius: Search radius in miles, e.g. 10
  • top_n: Number of top species to show per taxon, e.g. 3

Example: /top_species/Northfield/10/3

Leaderboard

See the top 100 contributors for a given animal in Minnesota.

/leaderboard/<animal>
  • animal: Common name of the animal, e.g. Common Loon

Example: /leaderboard/Common Loon

Game

Guess the most commonly observed animal in a randomly selected Minnesota location.

/game
  • No parameters needed — just visit the route to start playing
  • You'll be shown a location and four animal options to choose from
  • Submit your guess to find out if you're correct

Example: /game
